# 验证范围与来源边界

此工程从用户提供的60分钟录像重建，按最新请求采用原作英文像素画面。它是可操作的录像研究版本，尚不是取得原工程后可证明等价的完整游戏。

## 已经独立核验

- 21张手册页在1920×1080浏览器中按570×800原尺寸显示，逐像素对照为零差异；48个可拖标签通过真实鼠标拖放。此像素结果只覆盖手册区域。
- 42个录像估值由标签运算复算一致；共48项规则/所有权测试通过。
- DAY6至DAY11共53段来访/故事通过真实鼠标键盘操作，包含借款、罚款、教学、还款、举报和最后街头库存；测试只读取状态，不注入金钱、卡片或进度。
- 同类标签替换、错误品牌质疑、报价、拒绝、库存转移、上架0价、挂牌改价、保价移格、取下商品及日历入口另有专项实机验证。

具体运行证据以 `artifacts/qa/*report.json` 和 `docs/UI_SESSION_QA.md` 为准。完整流程通过并不等于全游戏所有像素、分支均通过。

## 默认的录像状态衔接

`followRecording`默认开启。53段开场余额保留了原帧数字与时刻；当进入下一段时余额不同，恢复该段可见余额，并写入只读的`checkpointLog`。办公室、夜间与结尾街头也有已标注的剪切状态。DAY11贷款页恢复录像已明确可见的未偿1500及Darcy已还清状态。

这意味着默认版本用于复走录像：自选报价造成的余额差异不保证跨片段保留。它没有把未知差额命名为奖励、罚款或其它交易。使用 `?continuous=1` 可保留连续现金；在缺少录像剪辑中操作的情况下，该模式不保证能按所有录像报价一直成交。

## 仍不能声称完全相同的部分

- 任意报价下的顾客接受阈值、耐心、随机数和传闻概率未由录像完整暴露。已录报价优先采用记录；其它报价使用暂定分支。
- 菜单目的页、未翻开的手册正文、未检测物品和未展示工具读数没有原始内容；不能由一个目录项推造整章。
- 角色是录像中提取的短循环，物品部分仍为原位场景片段。库存已有原槽映射，缺失的槽图仍有回退画法。动态非录像挂牌价格也不具备整张原挂牌图。
- 连续街道由原视频拼接，有源素材边界；B2返回B1的过程被剪去，Escape回B1是导航辅助。日末回店和未展示的跨日使用已见界面衔接，不能称为原作完整城市或全部每日结算内容。
- 登记处是广场窗口；维修店进入过程被剪去。缴费后的原对白继续会按录像片段切到维修内景，不能把途经GEM的门牌当作实际维修店入口。
- 举报第一次按下的两计数与现金变化有连续画面证据；第二次按下在剪切中缺失。重复顾客举报保护、跨日清零没有同等级的操作证据。没有添加按人群抓捕或举报赏金。
- 新显示的AVAC借款按钮按页面标明的5000额度实现；录像没有实际借入或到期还息片段。原音频目前是取样循环，不能称为完整原音轨。

这些限制保留在工程中，不以“构建成功”或“全流程跑通”替代用户的1:1视觉验收。
