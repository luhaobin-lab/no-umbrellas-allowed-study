# 本项目界面约定：原视频复现

本轮最新用户要求优先：以本地参考视频中的 No Umbrellas Allowed 1.0.5 英文像素界面、布局、书页与实际可见机制为目标。此前废土餐车、lowpoly、中国化文案全部不用于此构建。

- 固定1920×1080原坐标，宽高等比缩放；原图片不重排文字、不更改书页构图。
- 书籍裁切位于1350,155，尺寸570×800；左鉴定单60,348，345×505；报价器1486,526。
- 工具原槽底中704..1208,898..1000，六种格位保留；图标使用原生67×68而不撑满槽位。鼠标在物品上检测，相关原书页自动打开。
- 书籍标签必须由玩家拖入；错误判断、质疑品牌、替换标签和私槽分别保留。
- 真实键盘/鼠标控件透明覆盖图层；只在键盘Tab导航时显示焦点，不给鼠标操作新增高亮边框。
- 通用美术/独特构图不复制的技能建议，被用户明确要求视频1:1的指令覆盖。所有资产均来自用户提供视频的本地取样，不冒称原游戏工程源文件。
- 新增的界面仅限视频实际出现过的内容。未显示的设置、挑战模式、结局等入口不造假页面。
- 动态数字字模与补充标签字体从录像提取。PNG去掉颜色解释metadata，保留图像数据；书区域已与源RGB逐像素比对。

## 断点处理
录像有剪切与省略操作，记录了7处无法归因的余额跳变。默认按已告知用户的“断点存档衔接”方式，进入下一段有明确初始余额的录像状态时恢复其余额。这是重现录屏片段的衔接，不是罚款/奖励/随机收益规则。
`?continuous=1`保留连续余额，不使用这些录像断点；由于原录屏省略了部分收益/支出，该模式不会强行保证全程余额与视频一致。

## 验收
- 实际21书页在1920×1080、deviceScaleFactor1画布中，各456000像素与来源裁切完全一致；报告在artifacts/qa/book-report.json。
- 此项仅证明书页显示相同。不能用它证明整个游戏、所有背景动画、剪切外机制完全一致。
- 实际鼠标/键盘交互和全录屏来访序列必须额外核验，禁止用视频播放、注入状态或测试通过数量代替游戏验收。
